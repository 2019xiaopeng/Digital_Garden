## 一、总体结论

代码库功能完整、迭代活跃，但积累了三类系统性风险：

1. **局域网共享服务是最大的安全洞**（F1/F2）：`0.0.0.0` 绑定 + 零鉴权 + CORS 全开，开启后同网段任意设备可静默读改删全部数据。本次已堵住任意文件读取（F2），但鉴权（F1）需要一次专门改动。
2. **统计口径互相矛盾**（F34/F35，已修复）：周复盘统计的是自习室打卡秒数而非番茄钟专注，且窗口是滚动 7 天而非承诺的周一~周日，错误数据还会喂给 AI 周报。
3. **`lib.rs` 5707 行单文件 + 双轨数据层**是可维护性的最大负债（F52/F11）：171 个函数天然分三层，拆分是低成本高收益；TaskService 静默回退 localStorage 会让导入「假成功」。

依赖侧一次性清掉了 **204 个包**（9 个零引用依赖及其传递依赖），首屏 JS 从单一 1,524 kB 拆为 349 kB 入口 + 按路由加载。

## 三、高危待办（需要决策或较大改动，按优先级）

### 1. F1 · 局域网服务零鉴权（high, M）— 本次最优先
`toggle_local_server` 开启后 axum 绑定 `0.0.0.0:9527` + `CorsLayer::permissive()`，全部 `/api/*`（含任务删除、错题物理删除、文件上传）无任何鉴权；配合 CORS `*`，用户浏览器里的任意网页也能经 `127.0.0.1:9527` 读响应。
**修法**：启动时生成一次性 token，axum middleware 校验 `Authorization: Bearer`，设置页展示（可配二维码），前端 apiBridge 全部请求携带；CORS 收紧。约 30-40 行，集中在 router `.layer()` 一处。默认 `lanShareEnabled: false` 缓解但不消除风险。
（本次已先堵住它的任意文件读取伴生洞 F2。）

### 2. G1.1 · 「更改目录」是数据丢失级误导（high, S~M）
后端永远硬编码读写 `Documents/EVA_Knowledge_Base`，「更改目录」只在新路径建空目录骨架：数据不迁移、错题/聊天图片立即全部裂图、目录规划面板与备份指引全部指向空壳。
**建议**：删掉该按钮与后端 `initialize_workspace_at`/`ensure_workspace_dirs_at`（全仓仅此调用），docRoot 改为只读展示真实根；真要支持自定义根是 M/L 级独立需求。

### 3. F17 · AI 聊天长会话卡顿（high, 剩余部分）
本次已消除 processor 重建与不稳定 key；剩余：把单条消息抽成 `React.memo` 子组件，流式时只有变化的那条重渲。改动局限在 Notes.tsx 消息渲染块。

### 4. F25 · 专注中离开页面 focus_run 永远 running（medium, M）
污染完成率统计。需在 unmount/关窗路径把 running 记录结算为 aborted。

### 5. F15 · 笔记重命名/移动后前端路径簿记不更新（medium, M）
node.path 与 id 不刷新：文件打不开、预览被清空、批量删除报错。需要一次性的树更新重构。

### 6. F11 · 任务数据层双轨（medium, M）
TaskService 写库失败静默回退 localStorage，与全应用真实读路径（DB）分叉 → 导入提示成功但任务不出现。应删除回退、失败显式报错。

## 五、依赖升级路线（F45，两步走）

实测 `npm outdated`（2026-10-26）：vite 6.4.1→8.3.5、typescript 5.8.3→7.0.2、@vitejs/plugin-react 5.1.4→6.1.2、@tauri-apps/api 2.10.1→2.12.4、8 个 tauri 插件全部落后（plugin-fs 2.4.5→2.7.1、plugin-sql 2.3.2→2.6.0 等）；Cargo.lock 中 tauri crate 实际 2.10.2。

1. **低风险第一步**：@tauri-apps/api + cli + 8 个 JS 插件统一升到 2.12.x，与 Rust 侧 tauri crate 小步一起走。
2. **单独做第二步**：Vite 6→7→8 + @vitejs/plugin-react 6，升级后必须 `tauri build` 回归本地图片（asset protocol，参见 commit 4e2e280 的前车之鉴）。
3. **TypeScript 7 是编译器重写**：建议停在 5.9/6.x 观察，不要顺手带上。
4. Rust 侧：reqwest 0.11→0.12、tokio 特性收窄（F46）随下一次功能改动一起做。
